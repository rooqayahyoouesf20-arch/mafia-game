# لعبة المافيا (Mafia Game)

لعبة جماعية أونلاين بالعربية (RTL). الخادم بـ Node.js فقط **بدون أي مكتبات خارجية**، والتحديث الفوري عبر Server-Sent Events.

## التشغيل محلياً
1. ثبّت Node.js (الإصدار 16 أو أحدث).
2. داخل المجلد: `node server.js`
3. افتح `http://localhost:3000`.
4. للعب مع أصدقاء على نفس الشبكة: افتح `http://<عنوان-جهازك-المحلي>:3000` من جوالاتهم.

## النشر على الإنترنت
المشروع يحتاج استضافة تشغّل Node.js باستمرار (ليس استضافة ملفات ثابتة):
- **Render / Railway / Fly.io**: ارفع المجلد على GitHub، أنشئ Web Service، أمر البدء `node server.js`. المنفذ يؤخذ تلقائياً من `PORT`.
- **VPS**: `PORT=80 node server.js` (يفضّل `pm2 start server.js` + Nginx مع HTTPS).
- ملاحظة: الغرف محفوظة في ذاكرة الخادم، فإعادة تشغيله تنهي الغرف الحالية. يعمل على نسخة واحدة فقط.

## طريقة اللعب
1. أنشئ غرفة (عدد اللاعبين والمافيا) وشارك الكود، أو ادخل بكود صديقك. الحد الأدنى 4 لاعبين.
2. يكشف كل لاعب دوره على جهازه ويضغط «تم». المافيا يرون بعضهم فقط.
3. **الليل**: المافيا تختار ضحية، المحقق يتحقق من لاعب (✓ أخضر = مافيا، ✗ أحمر = ليس مافيا)، الدكتور يحمي لاعباً (يشمل نفسه).
4. **النهار**: يُعلن ما حدث، ثم نقاش ودردشة، ثم يضغط الجميع «جاهز» أو ينتهي الوقت ليبدأ التصويت.
5. **التصويت**: يُقصى صاحب أعلى الأصوات ويظهر دوره دائماً مع عبارة «كان بريئاً» أو «كان من المافيا». التعادل أو الامتناع = لا إقصاء.
6. تتكرر الجولات حتى النهاية. يفوز المواطنون بإقصاء كل المافيا، وتفوز المافيا حين يتساوى عددها مع البقية أو يزيد.

المؤقتات (في أعلى `server.js`): الليل 60ث، النقاش 180ث، التصويت 60ث.
